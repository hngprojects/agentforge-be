# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Commands

```bash
# Install dependencies
uv sync

# Start dev server
uv run fastapi dev app/main.py

# Run all tests (no live server required)
uv run pytest

# Run a single test file
uv run pytest tests/test_health.py

# Run a single test by name
uv run pytest tests/test_health.py::test_root

# Generate a migration after editing models
uv run alembic revision --autogenerate -m "describe change"

# Apply migrations
uv run alembic upgrade head

# Rollback one step
uv run alembic downgrade -1
```

## Architecture

**Request flow:** `app/main.py` → `app/api/v1/router.py` → `app/api/v1/endpoints/*.py` → `app/services/` → `app/db/session.py`

**Layers:**
- `app/core/config.py` — single `Settings` (pydantic-settings), env-driven. All settings accessed via the module-level `settings` singleton.
- `app/db/session.py` — async engine and `AsyncSessionLocal` factory. `get_session()` is the only DB entrypoint.
- `app/api/deps.py` — defines `DBSession = Annotated[AsyncSession, Depends(get_session)]`. Use this type annotation in endpoint signatures to inject a session.
- `app/models/` — SQLAlchemy ORM models subclassing `Base` from `app/models/base.py`. Every new model must be imported in `app/models/__init__.py` so Alembic autodiscovery works.
- `app/schemas/` — Pydantic request/response models, kept separate from ORM models.
- `app/services/` — business logic; endpoints should be thin (parse → call service → return).
- `app/api/v1/router.py` — aggregates endpoint routers; register new routers here with `api_router.include_router(...)`.

**Migrations:** Alembic reads `Base.metadata` and `settings.DATABASE_URL` directly from the app. Always review autogenerated migrations before applying — Alembic misses enum changes, server-side defaults, and some index renames. Never edit a migration that has been applied to a shared environment.

**Tests:** `pytest-asyncio` runs in `auto` mode — no `@pytest.mark.asyncio` needed. `conftest.py` provides an `AsyncClient` fixture backed by `ASGITransport` (no live server or DB required for most tests). The test `DATABASE_URL` is set via `os.environ.setdefault` in `conftest.py`.

## Conventions

- Absolute imports only: `from app.foo import bar`.
- Type-hint all function signatures; FastAPI uses them for validation and OpenAPI generation.
- Endpoints return Pydantic schemas or plain dicts, never raw ORM objects.
- Use `async def` for anything touching I/O (DB, HTTP, files); sync `def` for pure CPU work.
- New settings go in `Settings` in `app/core/config.py` and must also be added to `.env.example`.
